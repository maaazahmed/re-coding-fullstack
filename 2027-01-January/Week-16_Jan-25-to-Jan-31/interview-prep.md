### 1. Interview rounds and how to prepare

| Round | What they test | How to prepare |
|---|---|---|
| HR / screening | Communication, motivation, salary | Your story (below) |
| Online coding test | Data structures and algorithms (easy/medium) | The weekly coding problems |
| Technical: JS/React/Node | Concepts and live coding | The weekly quizzes and "say it out loud" lists |
| Machine coding | Build a small feature in 60–90 minutes | The timed tasks from Weeks 5–13 |
| System design (basic) | Architecture thinking | Weeks 14–15 |
| Project deep-dive | Your real experience | Weeks 11, 14, 15 |
| Behavioral | Teamwork and conflict | Your 6 STAR stories |

### 2. Final version of "Tell me about yourself" (60–90 seconds)
> "I'm a fullstack developer with **[X] years** of experience working with **React, Node.js, TypeScript and [DB]**.
> Most recently I **[built / worked on] [project or product]**, where I **[a concrete achievement with a number]**.
> I enjoy **[backend APIs / clean UI / solving performance problems]**.
> Recently I built **[Project 2]**, which uses **[key tech]**, to strengthen my **[skill]**.
> I'm looking for a role where I can **[what you want]**, and that's why this position interested me."

**Be ready for questions about AI use.** A good answer:
> "I use AI tools to speed up boilerplate and to explore ideas, but I design the solution and I review every line. I deliberately rebuilt my fundamentals so that I can work without them when needed."

### 3. Questions to ask the interviewer
- What does a typical day or sprint look like for this team?
- How do you do code reviews and testing?
- What are the biggest technical challenges right now?
- How do you measure success for this role in the first 3 months?

### 4. Final checklist
- [ ] CV: 1 page, achievements with numbers, links to GitHub and live projects
- [ ] LinkedIn updated (headline, about section, projects)
- [ ] GitHub profile README + 2 pinned projects with good READMEs and live links
- [ ] "Tell me about yourself" practiced 10 times out loud
- [ ] All "say it out loud" questions answered again
- [ ] 15 or more coding problems done without AI
- [ ] 4 or more machine coding tasks done under a timer
- [ ] 3 system design questions practiced on paper
- [ ] 6 STAR stories written
- [ ] 2 mock interviews done
- [ ] Final quiz score of 80% or more

## 🐍 Python track

### 🐍 Top Python interview questions (answer out loud)
- [ ] Mutable vs immutable types; the mutable default argument bug
- [ ] List vs tuple vs set vs dict, and their time complexities
- [ ] Decorators, generators and context managers
- [ ] `*args`/`**kwargs`; `is` vs `==`
- [ ] The GIL; threading vs multiprocessing vs asyncio
- [ ] FastAPI vs Django vs Flask: when would you use each?
- [ ] How does FastAPI validate data? What is `Depends`?
- [ ] How do you manage dependencies and environments (`uv`, venv, `pyproject.toml`)?
